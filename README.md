# sociology-reading-notes

> 社会学/人类学专著读书报告写作技能与实践案例
> 基于跨领域12篇顶级CSSCI期刊论文方法论提炼
> 产出1万字左右完整学术文章

## 📖 项目简介

这是一套面向社会学、人类学专业学生的**学术读书报告写作方法论**与**实践案例集**。

不同于常见的"读后感"或"内容摘抄"，本项目追求的是一种**问题驱动的学术性读书札记**——即：
- 不是复述一本书"讲了什么"，而是提炼它**一句话核心命题**
- 不是罗列章节要点，而是拆解它的**分层分析体系**与**辩证理论脉络**
- 不是泛泛地"联系实际"，而是与**当代学术前沿/现实问题对话**
- 不是随意地评价"好/不好"，而是从**理论贡献/理论局限/当代价值**辩证三层评价
- **产出1万字左右的完整学术文章**（非提纲式札记）

## 🎯 核心方法论：七步读书法（v4.0通用版）

| 步骤 | 名称 | 字数 | 核心问题 |
|------|------|------|----------|
| 1 | **问题意识提炼** | 约1500字 | 这本书要回答的核心问题是什么？一句话核心命题是什么？ |
| 2 | **学术史定位** | 约1500字 | 理论来源/理论对话/理论推进，三维展开 |
| 3 | **核心概念维度化拆解** | 约1500字 | 1-3个核心概念，从多个维度拆解 |
| 4 | **分析体系分层展开** | 约2000字 | 机制→结构→现象→主体，逐层展开 |
| 5 | **当代对话** | 约1500字 | 与当下学术前沿/现实问题的对话 |
| 6 | **出路/启示** | 约1000字 | 这本书提出了什么出路？对我们有什么启发？ |
| 7 | **辩证评价** | 约1000字 | 理论贡献/理论局限/当代价值 |

**总字数**：约10000字

## 📚 实践案例：《叛逆的城市》精读

### 最终版范文（约10000字）：《空间正义何以可能——读戴维·哈维〈叛逆的城市〉》

1. **问题的提出：空间正义何以可能？** — 从中国城市化现实切入，引出哈维的核心命题
2. **学术脉络：哈维在思想史上的位置** — 马克思→列斐伏尔→哈维→后现代主义的对话
3. **核心概念的拆解：城市权利的多重维度** — 生产权/分配权/全球权/环境权
4. **批判的展开：从机制到现象的四层分析** — 机制→结构→现象→主体
5. **与当代中国的对话** — 房价、绅士化、地铁、疫情、平台资本主义
6. **出路何在：可能性与路径** — 可能性条件/城市权利运动/中国语境启示
7. **评价：贡献、局限与当代价值** — 辩证三层评价
