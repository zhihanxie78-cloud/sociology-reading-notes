# sociology-reading-notes

> 社会学/人类学专著读书报告写作技能与实践案例

## 📖 项目简介

这是一套面向社会学、人类学专业学生的**学术读书报告写作方法论**与**实践案例集**。

不同于常见的"读后感"或"内容摘抄"，本项目追求的是一种**问题驱动的学术性读书札记**——即：
- 不是复述一本书"讲了什么"，而是提炼它"回答了什么学术问题"
- 不是罗列章节要点，而是拆解它的**核心概念结构**与**批判逻辑链条**
- 不是泛泛地"联系实际"，而是与**当下学术热点进行对话**
- 不是随意地评价"好/不好"，而是从**理论贡献/理论局限/当代价值**三个维度辩证评析

---

## 🎯 核心方法论：七步读书法（v2.0）

本项目从知网成熟学位论文（如曲阜师范大学《大卫·哈维城市空间正义思想研究》）中抽取了专业学者的解读逻辑，总结为以下七步写作流程：

| 步骤 | 名称 | 核心问题 |
|------|------|----------|
| 1 | **问题意识提炼** | 这本书在回答什么核心学术问题？我为什么关心这个问题？ |
| 2 | **理论脉络定位** | 谁影响了它？它在批判谁？它在学术谱系中处于什么位置？ |
| 3 | **核心概念维度化拆解** | 1-3个核心概念，从多个维度拆解（如正义→生产/分配/使用） |
| 4 | **批判逻辑链条** | 资本/权力结构 → 现象 → 非正义/问题 → 出路/方案 |
| 5 | **学术热点对话** | 本书观点如何回应当下的学术争论？ |
| 6 | **辩证评价** | 理论贡献 / 理论局限 / 当代价值 |
| 7 | **个人思考** | 从读者视角的延伸与疑问 |

### 与传统读书报告的区别

| 维度 | 传统读后感 | 本项目学术札记 |
|------|-----------|---------------|
| 出发点 | 内容复述 | 问题驱动 |
| 概念处理 | 笼统解释 | 维度化拆解 |
| 理论定位 | 介绍作者 | 三维脉络（来源/批判/位置） |
| 现实联系 | 联想式 | 对话式 |
| 评价方式 | 空泛好坏 | 辩证三分法 |

## 📚 实践案例：《叛逆的城市》精读

### 书籍基本信息
- **书名**：叛逆的城市——从城市权利到城市革命（Rebel Cities: From the Right to the City to the Urban Revolution）
- **作者**：[美] 戴维·哈维（David Harvey）
- **译者**：叶齐茂、倪晓晖
- **出版社**：商务印书馆
- **出版年份**：2014年6月第1版

### 全书结构
```
前言：亨利·列斐伏尔的展望

第一部分 城市权利（理论建构）
  第一章 城市权利
  第二章 资本主义危机的城市根源
  第三章 创造城市共享资源
  第四章 地租的艺术：全球化、垄断和文化的商品化

第二部分 叛逆的城市（政治实践）
  第五章 开拓反资本主义斗争的城市
  第六章 伦敦2011：野蛮的资本主义扑向街头
  第七章 占领华尔街：华尔街党遇到了它的复仇者
```

### 核心理论脉络
```
马克思（资本批判）
    ↓
列斐伏尔（空间生产理论、城市权利概念）
    ↓
哈维（历史-地理唯物主义、空间正义批判）
```

## 💡 使用建议

### 适合人群
- 社会学、人类学、人文地理学专业的本科生、研究生
- 需要撰写课程读书报告、学术书评的学生
- 准备保研/申博需要积累学术写作材料的同学

### 使用方法
1. 先阅读 `对比反思与技能完善.md`，理解方法论升级的逻辑
2. 参考 `叛逆的城市_读书札记实践.md`，学习完整的札记写法
3. 运用七步读书法，对你正在读的书进行实践
4. 与知网成熟论文对比，持续优化自己的写作
