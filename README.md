# sociology-reading-notes

> 社会学/人类学专著读书报告写作技能与实践案例
> 基于跨领域12篇顶级CSSCI期刊论文方法论提炼
> 支持三种产出模式：提纲版 / 简版报告 / 详尽报告

## 📖 项目简介

这是一套面向社会学、人类学专业学生的**学术读书报告写作方法论**与**实践案例集**。

不同于常见的"读后感"或"内容摘抄"，本项目追求的是一种**问题驱动的学术性读书札记**——即：
- 不是复述一本书"讲了什么"，而是提炼它**一句话核心命题**
- 不是罗列章节要点，而是拆解它的**分层分析体系**与**辩证理论脉络**
- 不是泛泛地"联系实际"，而是与**当代学术前沿/现实问题对话**
- 不是随意地评价"好/不好"，而是从**理论贡献/理论局限/当代价值**辩证三层评价

---

## 🎯 三种产出模式（按需选择）

| 模式 | 字数 | 特点 | 适用场景 |
|------|------|------|----------|
| **提纲版** | 3000-5000字 | 框架式札记，提纲挈领 | 读书笔记、复习提纲、课程预习 |
| **简版报告** | 约8000字 | 连贯学术散文，结构完整 | 课程作业、一般性读书报告 |
| **详尽报告** | 约15000字 | 带规范引用，透彻阐释 | 推免/申博材料、学术论文 |
