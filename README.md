# sociology-reading-notes

> 社会学/人类学专著读书报告写作技能与实践案例

## 📖 项目简介

这是一套面向社会学、人类学专业学生的**学术读书报告写作方法论**与**实践案例集**。

不同于常见的"读后感"或"内容摘抄"，本项目追求的是一种**问题驱动的学术性读书札记**——即：
- 不是复述一本书"讲了什么"，而是提炼它**一句话核心命题**
- 不是罗列章节要点，而是拆解它的**分层批判体系**与**辩证理论脉络**
- 不是泛泛地"联系实际"，而是从**城市+全球双维度**展开空间分析
- 不是随意地评价"好/不好"，而是从**可能性条件→意识→实践→联盟**系统分析出路

---

## 🎯 核心方法论：七步读书法（v3.0）

本项目从**顶级CSSCI期刊论文**（《马克思主义研究》《北京大学学报》）中抽取了专业学者的解读逻辑，总结为以下七步写作流程：

| 步骤 | 名称 | 核心问题 |
|------|------|----------|
| 1 | **核心命题提炼** | 这本书的一句话核心命题是什么？为什么重要？ |
| 2 | **理论脉络辩证** | 来源/对话/转向三维展开 |
| 3 | **核心概念维度化拆解** | 1-3个核心概念，从多个维度拆解 |
| 4 | **批判体系分层展开** | 机制→结构→现象→主体，四层批判 |
| 5 | **空间双维度展开** | 城市层面 + 全球层面 |
| 6 | **出路系统分析** | 可能性条件→意识→实践→联盟 |
| 7 | **辩证评价** | 理论贡献/理论局限/当代价值 |

### 方法论演进

| 版本 | 核心特征 | 对比基准 |
|------|----------|----------|
| v1.0 | 形式结构导向（总-分-总） | 普通课程作业 |
| v2.0 | 问题驱动导向（七步雏形） | 普通硕士学位论文 |
| v3.0 | 分层辩证导向（精准命题+分层批判+双维度） | **顶级CSSCI期刊论文** |

## 📚 实践案例：《叛逆的城市》精读

### 书籍基本信息
- **书名**：叛逆的城市——从城市权利到城市革命（Rebel Cities）
- **作者**：[美] 戴维·哈维（David Harvey）
- **译者**：叶齐茂、倪晓晖
- **出版社**：商务印书馆
- **出版年份**：2014年6月第1版

### 核心理论脉络
```
马克思（生产性正义、资本批判）
    ↓ 回应与发展
列斐伏尔（空间生产理论、城市权利概念）
    ↓ 扬弃与推进
哈维（历史-地理唯物主义、空间正义批判）
    ↓ 超越
后现代主义（差异性正义）
```

### 核心概念
- 城市权利（The Right to the City）
- 空间非正义
- 城市共享资源（Urban Commons）
- 不稳定的无产阶级（Precariat）
- 时-空修复（Time-Space Fix）

## 💡 使用建议

### 适合人群
- 社会学、人类学、人文地理学专业的本科生、研究生
- 需要撰写课程读书报告、学术书评的学生
- 准备保研/申博需要积累学术写作材料的同学

### 使用方法
1. 先阅读 `对比反思与技能完善.md`，理解v3.0方法论的升级逻辑
2. 参考 `叛逆的城市_读书札记实践.md`，学习完整的札记写法
3. 运用七步读书法，对你正在读的书进行实践
4. 与顶级CSSCI论文对比，持续优化自己的写作
